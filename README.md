## Как запустить

```bash
uv sync                          # окружение и зависимости
uv run bookshop variant          # параметры вашего варианта
uv run bookshop                  # приложение: http://127.0.0.1:8000, API: /docs
uv run pytest                    # все тесты
uv run python -m grader lab1     # автопроверка (lab1 … lab4 или all)
```
