# Коллекция HTTP-запросов (ЛР3)

Сюда кладётся коллекция запросов к API «Книжной лавки» с проверками ответов.
Выберите один инструмент:

- **Hurl 8** — файлы `*.hurl` прямо в этой папке. Запуск при работающем приложении:
  `hurl --test --variable base_url=http://127.0.0.1:8000 api-collection/*.hurl`
- **Bruno 4** — коллекция Bruno в этой папке (`bruno.json` или `opencollection.yml`,
  запросы в `.bru` или `.yml`). Запуск: `bru run --env local` из этой папки.

Адрес сервера не пишите в запросах напрямую: только через переменную `base_url`.
